# 工程配电柜 AI 设计智能体 Demo

这是面向客户沟通的交互式概念验证，展示从需求录入、参数解析、冲突提示、型号推荐到参数化图纸预览的产品流程。

## V0.3 演示能力

- 四阶段解析进度与扫描反馈
- 待确认问题人工处理与状态联动
- 极端参数触发演示规则拦截
- 示例 BOM 与采购边界提示
- 项目、型号、版本、设计人和图号动态联动
- 工程白底与 CAD 经典黑底模式切换

## 重要说明

- 当前版本使用演示数据，不会读取或上传用户选择的文件。
- AI 置信度、型号匹配度、规则结论和电气参数均为模拟结果。
- 图纸仅用于展示交互与参数化出图思路，不可作为工程设计或生产依据。

## 使用

直接访问 GitHub Pages 地址，或下载源码后双击 `index.html`。
